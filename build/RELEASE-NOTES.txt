17.11.1: patch release on top of 17.11; kernel #82 unchanged. Console gate: a first-run password set by the root console is now written as 0640 root:aik-gate when the aik-gate group exists (previously 0600 root:root, which locked non-root users out of the console after first boot); aik-console v12 normalises pre-existing gate files to the same contract at every console round. aik-console v12.1: fixes the non-root VGA console chain, which failed to start (rc=127 restart loop) on v11/v12 because the fbterm environment assignments were passed as shell words instead of via env -- found by the 17.11.1 bench on the real second-boot path; serial consoles were not affected. Credentials that exist but cannot be read are no longer treated as first-run: honest error screen, never the password setup wizard. aik-console v11: non-root consoles read the root-owned fbterm config (input method works; closes a local privilege-escalation path in the v10 chain). occ W2 decisions audited (one line per exit). Regression tests for the 11-22 fixes. Factory-tree hygiene gate added to the refresh and the ISO build (stray build-machine home directory, retired shell directory, stale desktop unit copy and runtime leftovers are rejected). Memory service (aikd) is unchanged from 17.11.
