## 三、内核控制面清单（AIKernel 自有接口权威表）

### 3.1 /sys/kernel/ai/（ai_sysfs.c；ai.enabled=0 时全部不创建）

| 节点 | 权限 | 作用 |
|------|------|------|
| `enabled` | 0644 | AI 总开关；写 1 幂等拉起 Runtime |
| `model_load` / `model_unload` | 0200 写 | 按名加载/卸载模型（CAP_SYS_ADMIN）；模型格式 AIKWMDL v1（Q31 定点 MLP 真推理） |
| `policy/refresh` | 0200 写 | 幂等扫描策略注册表建 `<name>` 开关（上限 64） |
| `policy/<name>` | 0644 | 单策略开关 |
| `policy/global_enable` | 0644 | 一键关闭全部 AI 决策执行（紧急停止） |
| `policy/max_impact_pct` | 0644 | 决策最大影响幅度（默认 50%；⚠️ 对 [0..1] 开关参数会 clamp 跳过单步翻转，翻转前先 echo 100） |
| `policy/rollback` | 0200 写 | 回滚 `all` 或十进制 decision_id |
| `policy/think` | 0200 写 | 感知→决策→执行触发：`<event_id>,<domain>,<type>,<value>`（可带 pid 5 段） |
| `policy/outcome` | 0200 写 | 闭环结果上报：`<decision_id>,<outcome>,<metric_delta>` |
| `policy/chain_dir` | 0644 | 因果链 CSV 导出根目录 |
| `stats/telemetry_emitted / telemetry_dropped / telemetry_sampled_skip / decisions_total / decisions_hit / decisions_hitrate_permille / runtime_state` | 0444 | 统计 7 节点 |

所有写操作统一 `capable(CAP_SYS_ADMIN)`，失败 -EPERM。

### 3.2 /proc/ai/（ai_procfs.c）

| 节点 | 权限 | 内容 |
|------|------|------|
| `status` | 0444 | runtime_state/enabled/log_level/model_path/ring 规格/采样率/模型表/每 CPU ring 统计 |
| `decisions` | 0400 + CAP_SYS_ADMIN | 最近决策日志（全字段零脱敏，最近在前） |
| `chains` | 0400 + CAP_SYS_ADMIN | 因果链（trigger→decision→outcome，最旧在前=训练样本顺序） |
| `control` | 0444 | 可控参数表只读出口（name/domain/[real\|reserved]/min/max/current/default） |
| `latency` | 0444 | 决策延迟统计 |
| `hitrate` | 0444 | 策略命中率 |
| `telemetry` | 0644 | 遥测流出口：读=排空各 CPU ring（raw 二进制/human 文本）；写=`format=raw\|human`、`reset`（需 CAP_SYS_ADMIN） |
| `sched/stats`+`sched/classify`、`vfs/stats`+`vfs/rates` | — | 子系统子目录 |

**注意**：`/proc/aikernel`（agent/ai/core/ai_core.c，agent 自有静态状态页）与 `/proc/ai/`（内核 AIKernel 状态面）是两个不同 proc 根。

### 3.3 NETLINK_AI 协议（include/uapi/linux/ai_netlink.h；CONFIG_AIKERNEL_NETLINK）

协议族编号 `NETLINK_AI = 31`；内核 socket 在 subsys_initcall 创建，ai.enabled=0 不创建。

| 命令 | 值 | 请求载荷 | 应答 | 权限 |
|------|----|----------|------|------|
| `AI_CMD_SENSE` | 16 | `ai_nl_sense{cpu(ALL=0xFFFFFFFF), max_records(1..4096), format(RAW/HUMAN)}` | `ai_nl_sense_ack{records,bytes,ai_err}` + 记录流（raw=23B 定长头+数据） | 无 CAP 要求（仅要求 ai.enabled）；单次回传上限 64KB |
| `AI_CMD_ACT` | 17 | `ai_nl_act{trigger_event_id, decision_type, domain(0..12), confidence, model_version, data[8]}`（v2 增 param 定向字段） | `ai_nl_act_ack{executed, hit, ai_err}` | CAP_SYS_ADMIN；落 ai_policy_execute |
| `AI_CMD_REG` | 18 | `ai_nl_reg{flags}` | `{ai_err, count}` | CAP_SYS_ADMIN；portid 登记 32 槽（异步推送预留） |

## 五、接口开发规范（新增接口必读，原《AI 函数调用接口指南》）

### 5.1 接口三类

| 类别 | 命名前缀 | 谁调用 |
|------|----------|--------|
| 感知接口 | `ai_telemetry_*` | 内核埋点自动调用 |
| 推理与控制接口 | `ai_*_hook` / `ai_policy_*` / `ai_control_*` | 内核决策点 + AI Runtime |
| 用户态通信接口 | `ai_runtime_*` / sysfs / procfs / NETLINK_AI / 工具注册表 | agent（aikernel-shell / aikctl / aikd） |

### 5.2 标准（一条不能少）

1. **命名**：`ai_ + 子系统 + _ + 动作`（hook / telemetry_* / policy_* / get / set）；
2. **签名**：统一返回 `enum ai_error`（AI_OK=0，负值错误码）；出参指针由调用者释放；参数 ≤6；禁止隐式全局状态；
3. **零回归**：`#ifdef CONFIG_AIKERNEL_XXX` + `static inline` 空函数兜底，n 配置行为与原生完全一致；
4. **全量数据**：感知接口不哈希、不脱敏、不省略、不截断；每事件带纳秒时间戳/pid/cpu/来源/类型/severity/原始内容；每决策可回溯（decision_id + trigger_event_id + outcome 因果链）；
5. **性能预算**：遥测写入 <100ns（实测 147~158ns）；AI Hook <5µs（实测 2.5~4.1µs）；决策执行 <200ns（实测 762~2187ns，TCG 环境）；BPF ai_query <10µs（实测 1480ns）。

### 5.3 agent 侧用户态接口规范（原 docs/12、13 节选）

- 风格：Kernel C（Tab 8 宽、80 列、`/* */` 注释、函数左花括号另起行）；文件小写下划线；命令 `cmd_` 前缀；
- 分层契约：Shell 只经 Runtime API；Runtime 只调 `communication_send()`；Backend 路由按 provider_type；Provider 虚函数表 `ai_provider_ops{init,connect,chat,stream,status,close}`；错误码逐层透传；禁止硬编码 API 地址/密钥；API Key 仅存 `~/.aikernel/model.toml`（权限 0600），不进日志；
- 配置：TOML，`~/.aikernel/{model,provider,network}.toml`；写入临时文件 + fsync + rename 原子替换；
- 证书：内置 Mozilla CA Certificate Store（ISRG Root X1、DigiCert Global Root CA）。

### 5.4 错误码速查（enum ai_error，agent 侧 ai_types.h）
